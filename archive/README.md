# Archive

Historical session logs and superseded documentation. These files are preserved for
reference but are **not living docs** — they describe past work, not the current state
of the project.

## What's Here

- **BUG-HUNT-R*.md** — Bug hunt session logs from rounds 2-11 (213 bugs found and fixed)
- **OVERNIGHT*.md** — Overnight AI session status reports
- **PLAN-TIER*.md** — Tiered development plans (phases 3-5)
- **PERF-R11.md** — Performance optimization round 11 (superseded by PERF-R12.md at root)
- **Research docs** — CODEBASE-SCAN, MOBILE-RESEARCH, VISUALS-RESEARCH, WEBGPU-PLAN, etc.
- **scripts/** — Old versions of test/perf scripts (e2e_test_r3.py through r11.py, perf_*.py)

## Current Documentation

For current state, see the root directory:
- `AGENTS.md` — Critical invariants (read first)
- `docs/FILE_MAP.md` — Line-by-line map of index.html
- `PERF-R12.md` — Current performance optimization details
- `BUGS.md` — Bug hunt log
- `README.md` — Project overview

## Bug Hunt Sessions

When running a new bug hunt session (via the `/bughunt` skill), create a file here:
`archive/bug-hunt/BUG_HUNT_SESSION_N.md` with date, scope, bugs found, and fixes.
